# اكتشاف مهم — رسوم Syriatel Cash الفعلية للتجار (مصدر رسمي مباشر، 2026-09-03)

يجاوب فجوة T1-C في research/PROGRAM.md — "عرفنا إن الـAPI موجود، مش عارفين بكام".

## من الموقع الرسمي (syriatel.sy/services/syriatel-cash):

**العمليات المجانية بالكامل:**
1. عمليات الدفع الخاصة بتطبيقات التجارة الإلكترونية ⭐⭐⭐ (هذا يخصنا مباشرة — أي دفع عبر تطبيقنا)
2. عمليات تحويل المبالغ الخاصة بحساب التجار إلى البنوك

**العمليات التي عليها رسوم:**
1. عمليات الدفع لحساب التاجر (⚠️ لاحظ التضارب الظاهري مع البند المجاني رقم ١ أعلاه — يحتاج توضيح: يبدو إن "الدفع عبر تطبيقات e-commerce" مجاني لكن "الدفع العادي لحساب التاجر" (مثلاً تحويل مباشر من عميل لتاجر بدون واجهة API) عليه رسوم — الفرق قد يكون بين معاملة API مباشرة ومعاملة يدوية)
2. تحويل من زبون لزبون
3. الدفع لمزوّدات خدمة الإنترنت
4. إلغاء المحفظة واسترداد المبالغ
5. تعبئة رصيد بطاقات سيريتل
6. دفع فواتير خطوط سيريتل

**من بوست فيسبوك رسمي لصفحة Syriatel Cash (سؤال وجواب تجريبي مع تاجر):**
> "والعمولة ٢٠٠ ل.س لخدمة سيريتل كاش" — رقم ثابت صريح (مش نسبة مئوية) لعملية سحب واحدة.
⚠️ هذا رقم من تعليق مستخدم واحد على منشور رسمي، مش جدول رسوم منشور رسمياً — يحتاج تأكيد مباشر قبل استخدامه في حسابات B3، لكنه أول رقم فعلي مرصود.

**ملاحظة إضافية من بحث سابق (٣ سبتمبر):** فيه خدمة سحب "بتنفذ يدوياً حالياً" (بوست إنستجرام) و"العمولة على طريقة السحب تعدّلت لتتناسب مع الشروط الجديدة المفروضة علينا" — إشارة لتغييرات تنظيمية أو تشغيلية حديثة على نظام السحب، تستاهل متابعة قبل الاعتماد على أي رقم قديم.

## حساب التاجر بلا سقف استقبال:
من مصدر ثانوي (مدونة): "لا يوجد حالياً حد أعلى لحساب التاجر عند استقبال دفعات إلكترونية من الحسابات الأخرى" — ده مهم لأي تاجر بحجم معاملات كبير، عكس حسابات الأفراد اللي غالباً بيكون عندها سقف.

## بوابات API ثالثة موجودة فعلاً (اكتشاف جديد):
اكتشفنا وجود **منصات وسيطة سورية جاهزة** بتوفر API موحّد لسيريتل كاش وشام كاش:
- **API SYRIA** (apisyria.com) — اشتراكات من ١٠$ شهرياً، تجربة مجانية ٢٤ ساعة، توثيق REST API كامل بالعربي، endpoints لفحص الرصيد والتحويل المباشر (`transfer_cash`) وشحن الرصيد.
- منصة تانية غير رسمية (melchersman.com/Ahminix) بتوفر API مشابه بتوثيق إنجليزي، بايثون SDK جاهز (`pip install PySyriatel`).

**الأثر:** ده يغيّر D9 (ليدجر الفلوس والتسوية) بشكل كبير — **مش لازم نبني تكامل مباشر مع Syriatel/Sham من الصفر**. فيه طبقة توحيد جاهزة وشغالة بالفعل (نفس فكرة TSA API اللي كان مذكور في المخ، لكن دول بدائل/إضافات حقيقية موجودة ومُوثّقة بشكل عملي جداً — مش مجرد إعلان). **يستاهل تقييم فني مباشر (هل الأمان/الموثوقية كافية لمعاملات تجارية حقيقية) قبل الاعتماد عليها**، لكنها تقلل عبء "onboarding مش self-service" اللي كان مذكور في المخ — التكامل التقني نفسه بقى أسهل حتى لو تسجيل حساب التاجر نفسه لسه محتاج زيارة فعلية.
