# تفكيك المرجع الثاني — طلباتي (Talabatey · com.talabatey · العراق)

> المصدر: ١٣ سكرين شوت · ٢٠٢٦-٠٨-٣١ · العملة د.ع (دينار عراقي) · المنطقة: ابو الخصيب / الحارثية / الجمهورية (البصرة)
> التطبيق نفسه يخدم **العراق والسودان وسوريا** — يعني هو منافس فعلي في سوقنا، لا مرجع محايد.
> **هذا المرجع يحلّ محل سونيك مارت كعمود فقري.** السبب في §١٠.

---

## المكتشف الأهم: التطبيق **مضيف أصداف (Shell Host)** لا سوبر-آب

سونيك مارت = شبكة أيقونات مسطحة، كل فيرتيكال بيفتح نفس الصدفة بكاتالوج مختلف.
طلباتي = **تطبيقان مختلفان جوه بايناري واحد**، وكل واحد بصدفة كاملة خاصة بيه:

| | صدفة التوصيل (الرئيسية) | صدفة **الأزياء والجمال** |
|---|---|---|
| البوتوم ناف | ٣ تابات: الرئيسية · الطلبات · المزيد | **٤ تابات**: الرئيسية · التصنيفات · السلة · المزيد |
| الهيدر | أبيض · بحث + شريحة منطقة + جرس | **أحمر كامل** · عنوان الوضع + زر `خروج ✕` |
| التصنيف | فئة واحدة → متاجر → منيو | **٣ مستويات**: تابات وضع ← ريل جانبي ← شبكة أوراق |
| السلة | لكل متجر، توصيل محلي | سلة منفصلة، شحن (٢٤ ساعة) |
| الصفحات القانونية | مشتركة | **"عن الأزياء والجمال" + سياسة خصوصية خاصة بيها** |

فيه **زر خروج من الوضع** (`خروج ✕`) — إقرار صريح إنك دخلت مكان تاني.

→ **ده بالظبط اللي إنت بتقوله: بنية تحتية واحدة، ومظهر يتكيّف.** مش نظرية — شغّالة ومشحونة في السوق.

## ١. الشاشة الرئيسية — تشريح كامل
```
┌─────────────────────────────────────────────┐
│ 🔍          [ابو الخصيب الحي العسكري ▾]   🔔 │  ← بحث · شريحة المنطقة · إشعارات
├─────────────────────────────────────────────┤
│ [بانر ترويجي  ازياء طلباتي — خصم ٧٠٪]   ✕  │  ← قابل للإغلاق
├─────────────────────────────────────────────┤
│ [فطور][مرطبات][بن وقهوة][تجهيزات][اسماك] → │  ← بلاطات فئات، تدرّج أحمر، أيقونات 3D
│ [الأزياء والجمال]                            │  ← مدخل الصدفة الثانية، منفصل بصرياً
├─────────────────────────────────────────────┤
│           [المحلات الاكثر شيوعاً 🏪]         │
├─────────────────────────────────────────────┤
│ [الكل][خصومات][يدعم المحفظة][توصيل طلباتي] │  ← ⭐ فلترة بالقدرة لا بالفئة
├─────────────────────────────────────────────┤
│ ┌─ كارت متجر ───────────────────────────┐  │
│ │ [كوفر كبير]                 [جيد جداً ⭐]│  │
│ │ جكن تاون          📍 الجمهورية          │  │
│ │ [حصري]      [🛵 التوصيل 10,500 د.ع]    │  │  ← سعر التوصيل ظاهر **قبل** الدخول
│ └────────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

**التفاصيل اللي تفرق:**
- **شريحة المنطقة في الهيدر** (`ابو الخصيب الحي العسكري ▾`) — المكان مواطن من الدرجة الأولى، مش مدفون في الإعدادات
- **فلاتر بالقدرة لا بالفئة**: `يدعم المحفظة` · `توصيل طلباتي` (توصيل المنصة مقابل توصيل المتجر) · `خصومات` — ده تصنيف **تشغيلي**، مش تسويقي
- **سعر التوصيل على الكارت** قبل ما تدخل المتجر — يقتل مفاجأة الشيك-أوت (وهي شكوى BeeOrder رقم ١)
- شارات متعددة الطبقات: `جيد جداً ⭐` (تقييم) · `حصري` (حصرية) · `جديد` (حداثة)

## ٢. صفحة المتجر
كوفر ملء العرض + بحث وسهم رجوع عائمين فوقه · الاسم · 📍المنطقة · `مشاركة` · `حصري` · `جيد جداً ⭐`

**شريط معلومات ٣ أعمدة** — وده اللي سونيك مارت مكنش عنده:
| وقت التوصيل | سعر التوصيل | **الحد الأدنى** |
|---|---|---|
| 00:30 – 01:00 | 10,500 د.ع | 4,000 د.ع |

**الوقت نطاق لا رقم واحد** (٣٠–٦٠ دقيقة) — أمانة أعلى من "يصل خلال ٤٥ دقيقة" الثابتة في سونيك مارت.
تابات المنيو أفقية: `الاكثر طلبا` (افتراضي) · المقبلات الباردة · السلطات · البطاطا مقلية...
صف الصنف: صورة + اسم + **وصف مكوّنات** + سعر أخضر.

## ٣. صدفة الأزياء والجمال — تصنيف ٣ مستويات
```
تابات الوضع:  [ركن الجمال] [نسائي] [رجال] [أطفال] [منزلية] [الكترونيات]
                                    ↓
ريل جانبي:     ملابس · أحذية · ساعات واكسسوارات · حقائب · ملابس داخلية · رياضة · مستلزمات مكتبية
                                    ↓
شبكة الأوراق:  جينز · جيليه · تيشيرتات · سويت شيرت · سكراب · سترة · طقم رسمي · شورت ...
```
- بانر كاروسيل + قسم `عروض موسم الأعراس` (شارات ٦٠٪/٥٠٪/٧٠٪) + `وصل حديثاً` + `توفير`
- **صفحة المنتج**: صورة · اسم · **`Levante Outlet ↗` (لينك للمتجر/البراند)** · `الألوان` (سواتش) · `المقاسات` (M) · **`متوفر لدى`** (تعدد بائعين لنفس المنتج!) · شريط ثابت أسفل: السعر + ستيبر + إضافة
- `35,000 دينار عراقي` — العملة مكتوبة بالكامل هنا، مختصرة `د.ع` في مكان تاني ⚠️ عدم اتساق

## ٤. رحلة الضيف — **بيبرهن مقترحك**
التصفح والسلة والوصول للشيك-أوت **كله بدون تسجيل دخول**.
الديالوج بيضرب عند **خطوة الدفع بالذات**:
> "يجب تسجيل الدخول اولاً — يجب عليك تسجيل الدخول اولاً لتتمكن من استخدام هذه الميزة، هل تريد تسجيل الدخول الان؟" [نعم] [لا]

→ الاحتكاك متأخر لآخر لحظة ممكنة. **بالظبط الموديل اللي طلبته.**

## ٥. السلة
حقل برومو كود (حد متقطّع) فوق · كروت أصناف فيها **اسم المتجر تحت اسم الصنف** (البيروتي) · ستيبر · شريط سفلي ثابت: السعر الكلي + `متابعة`.

## ٦. الشيك-أوت
- **كارت العنوان بمصغّر خريطة Google حقيقي** + اسم المنطقة (الحارثية) + `تعديل`
- ملخص: المطعم · عدد الأطباق · سعر الطلب · سعر التوصيل · **السعر الكلي** (أخضر)
- طريقة الدفع كـ bottom-sheet: `الدفع عند الاستلام` **[افتراضية]** · `بطاقة الائتمان` (فيزا/ماستر)
- **`اقرب نقطة دالة او ملاحظات للسائق`** (٠/١٠٠ حرف) ← حل العنونة العربي الحقيقي
- **`رقم هاتف اخر`** (٠/١١) ← رقم بديل، اعتراف بإن التليفون بيقفل
- زرّان: `اطلب الان` (أحمر) · `جدولة الطلب` (أسود)

## ٧. الجدولة — وعد محسوب لا وقت مختار
شريط تواريخ (٣١ أغسطس الاثنين → ٥ سبتمبر السبت) + منتقي وقت + **نص وعد محسوب**:
> "طلبك سيبدأ تحضيره يوم الاثنين، ٣١ أغسطس ٨:٣٦ **وسيصلك خلال نصف ساعة الى ساعة و٢٠ دقيقة من بدء التحضير**"

→ النطاق بيتحسب من **بدء التحضير** لا من وقت الطلب. أمانة هندسية: بيفصل اللي بيتحكم فيه عن اللي مش بيتحكم فيه.

## ٨. اللي لسه غايب حتى هنا
تتبّع لحظي على خريطة · حالات الفشل (إلغاء/نفاد/ارتجاع) · محفظة/نقاط ظاهرة (بيفلتر بـ`يدعم المحفظة` بس مفيش شاشة محفظة في الصور) · دردشة · تتبّع المندوب.

## ١٠. لماذا هذا هو العمود الفقري لا سونيك مارت
| المعيار | سونيك مارت (مصر) | **طلباتي (العراق)** |
|---|---|---|
| المعمار | صدفة واحدة، ٨ فيرتيكال مسطّحة | **مضيف أصداف** — نموذج قابل للتوسّع فعلياً |
| السوق | بلبيس فقط | **٣ دول** — مثبت عبر حدود |
| العنونة | نص حر فقط | خريطة + نقطة دالة + رقم بديل |
| الشفافية | رسوم تظهر في الشيك-أوت | **رسوم وحد أدنى قبل الدخول** |
| الوعد | ETA ثابت مكتوب | **نطاق محسوب من بدء التحضير** |
| الضيف | تسجيل أولاً | **ضيف حتى الدفع** |

**القرار:** طلباتي = العمود الفقري للمعمار والرحلات. سونيك مارت = يفضل مرجعاً **للمحفظة والنقاط والكاش-باك وهاتلي** (الأجزاء اللي طلباتي مش مغطيها). الاتنين مصادر، واحد بس هو الهيكل.
