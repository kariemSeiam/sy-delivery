# 0004 — مضيف الأصداف: بنية واحدة، مظهر يتكيّف

> **الحالة:** مسودة قوية · **مصدرها:** كريم (٢٠٢٦-٠٨-٣١) + [[../teardown/talabatey-iq]]
> **يحلّ:** D1 (جزئياً) · D2 · D3 · E2
> ⚠️ **SUPERSEDED جزئياً (٢٠٢٦-٠٩-٠٢):** **صدفة التجارة (أزياء/إلكترونيات) خارج النطاق** — قرار كريم مباشر، مش بحث. النطاق الحالي **٣ أصداف**: توصيل · سوق · هاتلي. الدايجرام والجدول تحت بيوثّقوا النموذج الأصلي بالأربعة للسياق التاريخي — الصدفة الرابعة معلَّمة كملغاة، ممسوحتش من الملف.

## النموذج الذهني اللي بيغيّر كل حاجة

التطبيق **مش تطبيق فيه أقسام**. التطبيق **مضيف** بيحمّل **أصداف (Shells)**، وكل صدفة منتج كامل ليه:
ناڤيجيشن خاصة · ثيم خاص · عمق تصنيف خاص · دلالات سلة خاصة · حتى صفحات "عن" و"خصوصية" خاصة.

طلباتي العراقي بيعمل ده **شغّال ومشحون** — صدفة التوصيل (٣ تابات، هيدر أبيض) وصدفة الأزياء (٤ تابات، هيدر أحمر، `خروج ✕`).
ده مش تنظير، ده مثبت في السوق.

```
                    ┌──────────────────────────┐
                    │      المضيف (Host)       │
                    │  هوية · جلسة · موقع     │
                    │  عنوان · سلة · دفع      │
                    └────────────┬─────────────┘
                                 │  يحمّل الصدفة حسب: المدينة + الفيرتيكال + إعداد العميل
        ┌────────────────┬───────┴────────┬──────────────────┐
        ▼                ▼                ▼                  ▼
  صدفة التوصيل     صدفة السوق       صدفة التجارة ❌     صدفة "هاتلي"
  مطاعم/وجبات      SKU/وزن/مخزون    (ملغاة ٢٠٢٦-٠٩-٠٢)   بلا كاتالوج
  ٣ تابات          فلاتر مخزون       أزياء/إلكترونيات    نص حر + تسعير بعدي
  توصيل فوري       سلة متعددة        شحن/مرتجع            عرض سعر ثم تنفيذ
```
النطاق الفعلي دلوقتي ٣ أصداف — التوصيل والسوق وهاتلي بس. الرابعة فاضلة في الدايجرام كمرجع تاريخي مش كنطاق حالي.

## القواعد

1. **المضيف يملك:** الهوية، الجلسة، الموقع، دفتر العناوين، الدفع، الليدجر، الإشعارات. الصدفة **متعملهمش تاني أبداً**.
2. **الصدفة تملك:** الناڤيجيشن، الثيم (توكنات)، شكل الكاتالوج، الفلاتر، دلالات السلة، نصوصها القانونية.
3. **الصدفة تتحدّد بإعداد (config) لا بكود.** إضافة فيرتيكال = صف إعداد + توكنات، لا فرع في التطبيق.
4. **مؤشر الوضع دايماً ظاهر.** المستخدم لازم يعرف هو فين، وإزاي يخرج (`خروج ✕`).
5. **السلة لكل صدفة.** سلة مطعم وسلة أزياء ميختلطوش — دلالات التوصيل والمرتجع مختلفة تماماً.

## ⚠️ التعارض المفتوح مع D1

كلامك: *"بنية تحتية واحدة · كل عملائنا ومتاجرنا عليها · داشبورد لكل حاجة · حتى متجر لينا إحنا"* = **multi-tenant**.
وإجابتك على Q3: *"ملك العميل بالكامل"* = **single-tenant**، وقفلت D1 عليها من ساعتين.

**الاتنين ميقدروش يقفوا مع بعض.** التوفيق المرجّح: **العميل يملك نسخته، وبوصلة تملك المنصة** — لكن ده **قرار تجاري** مش معماري، ومحتاج جملة واحدة منك.
→ **D1 اترجعت لـ `مسودة`** لحد ما تحسمها. قفل بيتناقض معاه صف مفتوح أخطر من صف مفتوح.
