# قرار C3 — دورة حياة الطلب + حالات الفشل
> الحالة: **مسودة قوية** — مستقلة عن المدينة، جاهزة للقفل بمجرد موافقتك
> المرجع (سونيك مارت) غطّى ٥ حالات فرحة بس. هنا الفشل هو المنتج.

## ١. الحالة الأساسية (Happy Path)
```
تم الإنشاء → مؤكَّد → قيد التحضير → جاهز → مع المندوب → تم التوصيل
```
كل انتقال = event في event log (مش overwrite لحالة). كل event له timestamp + actor (نظام/تاجر/مندوب/عميل).

## ٢. أفرع الفشل — لازم تتصمم من أول يوم
| الفرع | يحصل إمتى | الأثر على الليدجر |
|---|---|---|
| **رفض التاجر** | التاجر مقفول فعلياً أو مش قادر ينفّذ | استرداد كامل فوري (نقدي: إلغاء تسوية / محفظة: رد فوري) |
| **نفاد منتج بعد الطلب** | SKU أو بند من المنيو خلص وقت التحضير | التاجر يعرض: استبدال (يوافق عليه العميل) أو حذف البند وتعديل الإجمالي |
| **إلغاء العميل** | قبل/بعد التأكيد، بنافذة زمنية محددة | لو قبل "قيد التحضير" → استرداد كامل بلا سؤال. بعدها → قد يتحمّل رسوم جزئية |
| **فشل التوصيل** | العنوان غلط / مش موجود / رفض الاستلام | إعادة محاولة محدودة العدد → بعدها يرجع للتاجر أو يُعتبر مرتجع |
| **تأخير SLA** | تجاوز ETA المعلن بنسبة محددة | إشعار تلقائي للعميل + تعويض (كوبون/نقاط) — تحديد النسبة يحتاج قرار G5 |
| **نزاع بعد التسليم** | "الطلب مش اللي اتفق عليه" | تذكرة نزاع → مراجعة (بشرية في المرحلة ١، شبه آلية بعدين) |
| **مرتجع جزئي** | جزء من الطلب مرفوض عند الاستلام | تعديل الإجمالي + رد الفرق فقط |

## ٣. تعديل خاص — "هاتلي" (بدون كاتالوج)
مسار مختلف بالكامل لأنه بلا سعر معروف مسبقًا:
```
طلب نصّي حر → (اختياري: عرض سعر تقديري) → قبول العميل → تنفيذ → تسعير فعلي بعد الشراء → دفع
```
نقطة الفشل الخاصة به: **الفارق بين السعر التقديري والفعلي**. لازم سقف نسبة اختلاف (مثلاً ±15%) يستوجب موافقة العميل قبل التسليم، وإلا نزاع مضمون.

## ٤. تعديل خاص — الكاتالوج بالوزن (بن وعطارة، ألبان محتمل)
الكمية الفعلية بعد التوزين قد تختلف عن المطلوب. نفس منطق التعديل الجزئي في §٢، لكن الفرق هنا **طبيعي متوقع** لا استثنائي — يحتاج نطاق تفاوت مقبول (tolerance) بدل "رفض/قبول".

## ٥. الأثر المعماري (يغذّي D9)
كل فرع فوق = حركة في **event log** + **ledger entry**، مش تعديل مباشر لحقل `status`. من غير ده:
- التسوية مع التاجر تبقى غير قابلة للتدقيق (مفيش سجل ليه اتغيّر المبلغ)
- الدعم (C7) هيشتغل بالعين مش بالبيانات
- أي تقرير مالي بعدين محتاج إعادة بناء كامل

## القرار المطلوب منك
هل تقفل هذا المسار كما هو؟ لو نعم، البند الوحيد المفتوح فيه هو **نسب التأخير والاسترداد الدقيقة** (G5) — قابلة للتحديد وقت الإطلاق، لا تمنع القفل المعماري الآن.
